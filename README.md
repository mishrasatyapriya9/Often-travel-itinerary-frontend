# 🌏 Travel Itinerary Management System - Frontend
This repository contains the React frontend implementation for the Thailand Travel Itinerary system, allowing users to explore, create, and view detailed travel itineraries for Thailand.
Features
* **Explore Thailand Itineraries**: Browse through curated itineraries for Phuket and Krabi
* **Recommendations**: Get personalized itinerary recommendations based on trip duration
* **Create Itinerary**: Build custom itineraries with an interactive interface
* **Itinerary Details**: View comprehensive day-by-day breakdown of activities, hotels, and transfers
Tech Stack
* **React 18** - Frontend library
* **React Router 6** - Navigation and routing
* **Redux Toolkit** - State management
* **Tailwind CSS** - Utility-first CSS framework
* **React DnD** - Drag and drop for the itinerary builder
* **React Query** - Data fetching and caching
* **Axios** - HTTP client
* **React-Leaflet** - Interactive maps
* **Framer Motion** - Animations and transitions
* **Vite** - Build tool and development server
Setup Instructions
Prerequisites
* Node.js 16+ (LTS recommended)
* npm 8+ or yarn 1.22+

## 🚀 Getting Started

Instructions on how to run frontend locally can be added here.

Environment Setup
1. Clone the repository:

```
git clone https://github.commishrasatyapriya9/Often-travel-itinerary-frontend
cd Often-travel-itinerary-frontend
```

2. Install dependencies:

```
npm install
# or
yarn install

Running the Application
Start the development server:
npm run dev
# or
yarn dev

```

This project was built as part of a Full Stack SDE Intern assignment. It includes a backend developed with **FastAPI** and **SQLAlchemy**, along with a frontend to explore and manage travel itineraries, with a focus on trips to **Thailand**.
